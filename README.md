# Сервисный центр (1С 8.3)

## Описание
Конфигурация для автоматизации работы сервисного центра по ремонту техники. Разработана на платформе 1С:Предприятие 8.3 (управляемые формы). 

## Состав репозитория
*   **/src** — исходный код конфигурации в формате XML.
*   **/demo_base** — файл выгрузки информационной базы (.dt) с тестовыми данными.

## Реализованный функционал

### Ремонты и CRM
*   Регистрация входящих обращений (документ «Прием в ремонт»).
*   Учет выполненных работ и использованных запчастей (документ «Заказ-наряд»).
*   История ремонтов в разрезе серийных номеров и IMEI устройств.
*   Отслеживание этапов ремонта через статусы.

### Складской учет
*   Поступление запчастей от поставщиков и прочее списание.
*   Ведение учета по партиям (метод FIFO).
*   Контроль остатков при проведении документов.

### Ценообразование
*   Хранение цен поставщиков.
*   Формирование прайс-листов (документ «Установка цен номенклатуры»).
*   Расчет розничных цен по матрице наценок.

### Финансы и взаиморасчеты
*   Учет наличных денежных средств (ПКО, РКО).
*   Учет задолженности перед поставщиками и долгов клиентов.
*   Взаиморасчеты с сотрудниками.

### Кадры и зарплата
*   Учет кадровых событий (прием на работу, увольнение).
*   Расчет сдельной оплаты труда на основе процента от выработки в заказ-нарядах.

## Архитектура и технические детали
*   **Подсистемы:** Конфигурация разделена на функциональные блоки: Ремонты, Склад, Финансы, Персонал, Аналитика.
*   **Права доступа:** Настроены роли и RLS.
*   **Отчетность:** Отчеты реализованы на базе Системы компоновки данных (СКД).
